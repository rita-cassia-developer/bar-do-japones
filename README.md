# 🚀 Landing Page Comercial - Bar do Japonês

![Status](https://img.shields.io/badge/Status-Concluído-brightgreen)

## 📝 Descrição do Projeto

Este projeto consiste em uma **landing page comercial** desenvolvida para o "Bar do Japonês", um comércio familiar. O objetivo principal foi criar uma presença online atraente e funcional, demonstrando habilidades em **desenvolvimento web, Clean Code, responsividade e acessibilidade**. A página foi concebida para apresentar o estabelecimento, seus produtos e informações de contato de forma clara e intuitiva.

## ✨ Funcionalidades

*   **Design Responsivo:** Layout adaptável a diferentes tamanhos de tela (desktops, tablets e smartphones), garantindo uma experiência de usuário consistente.
*   **Navegação Intuitiva:** Estrutura de navegação simples e direta para facilitar o acesso às informações.
*   **Informações Comerciais:** Apresentação de detalhes sobre o bar, como cardápio (imagens), localização e horários de funcionamento.
*   **Contato:** Seção dedicada com informações de contato e, potencialmente, um formulário ou links para redes sociais.
*   **Acessibilidade:** Implementação de boas práticas para garantir que a página seja utilizável por pessoas com diversas necessidades, incluindo semântica HTML e contrastes adequados.

## 🛠️ Tecnologias Utilizadas

*   **HTML5:** Utilizado para estruturação semântica do conteúdo, seguindo as melhores práticas para SEO e acessibilidade.
*   **CSS3:** Responsável pela estilização avançada, incluindo layout flexível, animações e transições, com foco em um design moderno e responsivo.
*   **Clean Code:** Aplicação de princípios de código limpo para garantir a legibilidade, manutenção e escalabilidade do projeto.

## ⚙️ Como Rodar o Projeto Localmente

Para visualizar e testar o projeto em sua máquina, siga os passos:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/rita-cassia-developer/bar-do-japones.git
    ```
2.  **Navegue até o diretório do projeto:**
    ```bash
    cd bar-do-japones
    ```
3.  **Abra o arquivo `index.html` no seu navegador:**
    Basta arrastar o arquivo `index.html` para a janela do seu navegador ou utilizar uma extensão de servidor local (como o Live Server do VS Code) para uma visualização mais prática.

## 💡 Desafios e Aprendizados

Este projeto foi uma excelente oportunidade para aprimorar as seguintes habilidades:

*   **Design Responsivo:** Implementação de técnicas de CSS para garantir que o layout se adapte perfeitamente a qualquer dispositivo.
*   **Clean Code:** Refatoração e organização do código para torná-lo mais legível, manutenível e escalável.
*   **Acessibilidade Web (WCAG):** Aplicação de diretrizes de acessibilidade para criar uma experiência inclusiva para todos os usuários.
*   **Otimização de Imagens:** Gerenciamento e otimização de ativos visuais para garantir o carregamento rápido da página.

*   **Clean Code:** Código bem estruturado e indentado, seguindo padrões de legibilidade.
